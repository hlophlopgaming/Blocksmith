# Changelog

## 0.8.3

- Постоянный переключатель «Игнорировать правила Blocksmith» на самом меше,
  доступный в Object Mode и Edit Mode. Проверки ряда объектов также учитывают флаг.
- При отказе вернуть защиту сохраняются ручные правки и положение меша.
- Интерфейс на английском, испанском, французском, немецком и русском языках
  через штатную систему переводов Blender, включая параметры, подсказки и сообщения.
- README на тех же пяти языках; подробная русская инструкция сохранена отдельно.

## 0.8.2

- Метка «Свободное размещение» для выделенных мешей: перемещение, пересечения,
  отражения и ручная правка без отката защитой Blocksmith.
- Метка сохраняется в `.blend`, при копировании и запекании. Помеченные меши
  остаются доступны для привязки и экспорта. Снятие метки с конфликтующего
  модуля отклоняется без перемещения или удаления меша.
- Подготовка исходников к GitHub: GPL-3.0-or-later, исключение локальных
  артефактов из Git, сборка расширения и проверки в GitHub Actions.

## 0.8.1

- Общая привязка генераторов к видимым вершинам и рёбрам готовых мешей,
  включая результаты Boolean и Array.
