# Проверка 0.8.3

Дата: 2026-11-13. Blender 5.3.0, Linux.

- Python: 11 тестов CLI, упаковки и каталога переводов — PASS.
- `immunity_ui_check.py` — PASS: переключатель присутствует в Edit Mode;
  пересечения и вывернутые нормали помеченного модуля сохраняются;
  соседний непомеченный модуль остаётся защищённым. Отказ вернуть защиту,
  в том числе после правок в Edit Mode, не уничтожает геометрию пользователя.
- `free_placement_check.py` — PASS: трансформации, пересечения в обе стороны,
  копирование, запекание, сохранение/загрузка, GLB и проверка Undo/Redo.
- `guard_check.py` — PASS: защита непомеченных модулей, родители, ручные
  правки, Boolean и проверка перед экспортом.
- `blender_check.py` — PASS: все формы, параметры, UV, pivot, GLB и регистрация.
- `localization_check.py` — PASS: реальные переключения локали Blender между
  английским, испанским, французским, немецким и русским; все подписи параметров
  и перечислений покрыты каталогом; регистрация/отключение повторяются без ошибок.
- Каталог переводов проверен на полноту пяти языковых колонок и сохранение
  подстановок форматирования. Проверены относительные ссылки пяти README.

Установлено в пользовательский Blender через штатный оператор расширений.
При обновлении сохранены параметры сцены и объектов, создана резервная копия
сцены без перезаписи рабочего файла. Подтверждены версия 0.8.3, включённое
расширение и работающий таймер защиты. На выбранном `BS_Block.001` включён флаг.

Ограничение завершения фонового Blender из отчёта 0.8.2 остаётся: после assert
тестовый процесс завершался через `os._exit(0)`. Полная ручная оценка всех пяти
вариантов интерфейса, новый прогон Godot/FBX и GitHub Actions не выполнялись.

вне песочницы автоматически отклонён (`sandbox_approval: false`).
