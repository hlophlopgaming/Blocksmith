# Проверка 0.8.2

Дата: 2026-11-12. Blender 5.3.0, Linux.

- 10 Python-тестов CLI и установочного ZIP — PASS.
- Проверка синтаксиса Python — PASS.
- `free_placement_check.py` — PASS: перемещение и пересечения в обе стороны,
  отрицательный масштаб, вывернутые нормали, независимость от отката соседнего
  модуля, безопасное снятие метки, массовое назначение, копирование, запекание,
  сохранение/загрузка `.blend`, GLB и восстановление метки при недопустимом Undo.
- `guard_check.py` и `guard_scope_check.py` — PASS: обычная защита модулей,
  нативные трансформации, масштаб родителя, ручные правки, Boolean и экспорт.
- `blender_check.py` — PASS: все формы, параметры, UV, pivot, ручные правки,
  экспорт GLB, сохранение и повторная регистрация.
- `native_adoption_check.py` — PASS, включая сохранение метки при преобразовании.

Ограничение окружения: оба установленных Blender (5.2.3 и 5.3.0) зависают при
обычном завершении даже пустого фонового запуска, сообщая `pa_write(): Operation
not permitted`. Итоговые Blender-проверки запускались через `runpy.run_path`;
после успешного выполнения всех assert вывод сбрасывался, процесс завершался
через `os._exit(0)`. Обычное завершение Blender в этом окружении не подтверждено.

Ручная проверка панели, новая проверка в Godot/FBX, интеграционный CLI-прогон
и запуск GitHub Actions в этой сессии не выполнялись. Код CLI не менялся,
кроме указания лицензии. Публикация на GitHub и установка в текущую
пользовательскую сессию Blender не выполнялись.
