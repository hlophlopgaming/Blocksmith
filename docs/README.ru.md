# Blocksmith

[English](../README.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский**

Создавайте редактируемые блочные прототипы уровней в **Blender 5+** и экспортируйте их в **Godot**. Версия **0.8.3**, лицензия **GPL-3.0-or-later**.

Blocksmith — самостоятельная реализация по публичному описанию рабочего процесса BlockD. Полного совпадения функций с BlockD нет. Интерфейс поддерживает английский, испанский, французский, немецкий и русский языки. Выберите язык в **Edit → Preferences → Interface → Translation** и включите **Interface** и **Tooltips**. Blocksmith использует язык Blender; имена существующих объектов сохраняются.

## Возможности

- Рисование стен, полов, комнат, лестниц и пандусов прямо во вьюпорте; 32 готовых модуля с превью.
- Изменение размеров через боковую панель и ручки во вьюпорте. Двери, окна, арки, крыши, перила и кривые стены.
- Привязка к сетке, видимым вершинам и рёбрам, включая результат Boolean и Array. Угловые, прямые и Т-стыки стен.
- Неразрушающее рисование проёмов на объёмных мешах; повторение объектов и отверстий инструментом ряда.
- Соединение двух уровней прямой лестницей или пандусом. Фигуры персонажа и подсказки для ступеней, проходов, укрытий и уклонов.
- Текстуры Kenney, игровые теги, экспорт GLB и FBX.
- Постоянный флаг **«Игнорировать правила Blocksmith»** на меше, доступный в Object Mode и Edit Mode.
- Генерация из проверяемого JSON через Python CLI без установки аддона в личную сессию Blender.

## Установка

1. Скачайте `blocksmith-0.8.3.zip` из [Releases](https://github.com/hlophlopgaming/Blocksmith/releases) или соберите архив из корня репозитория:

   ```sh
   python3 tools/package.py
   ```

2. В Blender откройте **Edit → Preferences → Get Extensions → меню справа сверху → Install from Disk**. Выберите скачанный ZIP или `dist/blocksmith-0.8.3.zip` и включите расширение.
3. В 3D-виде нажмите **N** и откройте вкладку **Blocksmith**.

Для сборки нужен Python 3.10+, сторонние Python-библиотеки не требуются. Автоматические архивы GitHub **Source code** содержат исходники и не подходят для установки расширения.

## Быстрый старт

1. Нажмите **Рисовать конструкции** или **Shift+Alt+D**.
2. Выберите форму в верхнем ряду или в блоке **Следующая конструкция**. **Объекты с превью** открывает каталог модулей.
3. Протяните ЛКМ и отпустите, чтобы создать конструкцию. Выделите её для изменения размеров или потяните оранжевые ручки.
4. **Повторять** оставляет инструмент активным. **Esc / ПКМ** отменяет незавершённый жест или возвращает выделение.

При обычном рисовании **Ctrl** временно отключает привязку, **Shift** ограничивает направление шагом 45° или делает квадратное основание, **H** меняет высоту, **F** разворачивает лестницу или пандус. Между жестами доступны навигация и панель.

Для прямой лестницы или пандуса тяните от нижнего пола к верхнему краю площадки; обратный жест тоже работает. Для двери, окна или арки нарисуйте прямоугольник на объёмном меше: каждый проём добавляет отдельный Boolean-вырез. Кривые стены создаются точками, свободной линией или дугой по трём точкам. Подробности отдельных инструментов сохранены в [полной русской инструкции](manual.ru.md).

## Игнорирование правил

Выделите меш и включите **N → Blocksmith → Игнорировать правила Blocksmith**. Это сохраняемый флаг самого объекта. Он доступен и во время редактирования меша. Для нескольких выделенных объектов используйте **Применить к выделенным**.

Помеченный меш можно двигать внутрь других объектов, поворачивать, масштабировать, отражать отрицательным масштабом и редактировать вручную, включая переворот нормалей. Blocksmith исключает его из проверок пересечений и откатов. Другие модули также могут его пересекать. Геометрия, материалы и игровые теги сохраняются, как и флаг при копировании, запекании и сохранении/загрузке `.blend`. Привязка и экспорт продолжают работать, если роль объекта сама по себе не исключает его, как у резака или фигуры персонажа.

Выключение флага возвращает обычную защиту модуля. Если его текущее состояние нарушает ограничения, защита не включается: меш и его правки сохраняются. Сначала исправьте пересечения, масштаб или нормали. Обычные меши Blender не ограничиваются и без флага. Поддерживаются Undo/Redo.

Из скрипта:

```python
obj.bs.free_placement = True  # постоянный флаг конкретного объекта
bpy.ops.blocksmith.free_placement(enabled=True)  # все выделенные меши
bpy.ops.blocksmith.free_placement(enabled=False)
```

Флаг отключает проверку: пересечения и ошибки геометрии могут попасть в экспорт. Привязка Blender и подсказки размеров настраиваются отдельно. Трансформация родителя всё ещё может быть отменена, если затрагивает защищённого потомка.

## Защита геометрии

Непомеченные модули Blocksmith отклоняют пересечения, отрицательный и нулевой масштаб, незамкнутую сетку и вывернутые нормали. Касание граней разрешено. Проверяется фактическая геометрия после модификаторов, а не только габариты. Обычные и импортированные меши, reference-фигуры, вода и используемые Boolean-резаки исключены из проверки твёрдых модулей.

Защита работает при операциях аддона, обычных трансформациях, выходе из Edit Mode и Undo/Redo. Экспорт повторно проверяет защищённые модули. При открытии существующей сцены объекты не удаляются, но конфликты защищённых модулей нужно исправить перед экспортом. Вычисления численные; в сложных сценах возможны задержки. Это не математическое доказательство отсутствия пересечений.

## Экспорт в Godot

Откройте **Экспорт в Godot**, выберите **GLB** или **FBX**, область экспорта, папку и имя файла. Перед использованием относительного пути сохраните `.blend`.

Основной проверенный формат — GLB. При включённых коллизиях твёрдые меши получают суффикс Godot `-col`. Вода экспортируется видимой, без коллизии. Фигуры персонажа, используемые резаки, скрытые архивы исходников и временные объекты защиты исключаются. Кривые стены превращаются в меши. Существующие файлы не перезаписываются: выберите другое имя или папку.

## JSON CLI

Из корня репозитория, с Python 3.10+ и Blender 5+ в `PATH`:

```sh
python3 tools/levelgen.py shapes
python3 tools/levelgen.py presets
python3 tools/levelgen.py schema
python3 tools/levelgen.py validate examples/courtyard.json
python3 tools/levelgen.py generate examples/courtyard.json --out-dir generated/courtyard
```

Создаются `level.blend`, `level.glb`, `level.spec.json`, `report.json` и `blender.log`. `--blender /путь/к/blender` задаёт другой исполняемый файл, `--overwrite` заменяет предыдущий результат. Blender работает в отдельном фоновом процессе; ошибка проверки сохраняет прежний экспорт. Вывод — JSON, ошибки идут в stderr с ненулевым кодом завершения.

Спецификация использует **метры**, координаты Blender с **Z вверх** и углы Эйлера в **градусах**. GLB преобразует их в Y-up для Godot. См. [схему](../examples/level.schema.json), [примеры](../examples/) и команду `schema`. Неизвестные ключи, повторные имена, некорректные числа и чрезмерная сложность отклоняются. JSON не выполняет Python. Флаг игнорирования правил — настройка меша в Blender; в текущую CLI-схему он не входит.

## Текущие ограничения

Blender 5.0 заявлен как минимум, но отдельно не проверялся. Ранее проверки выполнялись на Blender 5.2.3, 5.3.0 и Godot 4.7.2. FBX проверен слабее GLB. Цепочки стен не замыкаются автоматически; изменение одной стены не двигает соседние. Для независимых редактируемых копий используйте **Shift+D**: **Alt+D** разделяет меш, но не параметры. Apply Scale поддерживает положительный равномерный масштаб неизменённого параметрического меша с одним пользователем. Подсказки не моделируют игровой контроллер. Экспортируемые коллизии — статические треугольные сетки. Для готовой игры геометрию blockout может потребоваться оптимизировать.
